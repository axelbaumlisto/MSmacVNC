# Permissions: система, идентичная clipshot

Единственный действующий план. Редакция 2 — после ревью (3 критика,
`/tmp/rev4/REV_{restart,ui,gaps}.md`, 7 блокеров к редакции 1).

## Правило работы

**От плана не отступаем.** Ничего вне списка шагов. Каждый шаг заканчивается
проверкой, которая способна поймать регрессию.

## Почему предыдущие попытки провалились

| Что сделал | Чем обернулось |
|---|---|
| Правило «перезапуск только через `open`» | ложное; породило всю сломанную конструкцию |
| sh-хелпер + ожидание pid + `open -n` | удержание порта, двойной экземпляр, отказ LaunchServices |
| SIGTERM-источник + авто-перезапуск | **приложение стало незакрываемым**, ломало logout |
| Модальная панель `runModal` | глотала `terminate:`, прятала подсказку под системным алертом |
| Зонд `getShareableContent` при старте | поднимал системный диалог в not-determined |

## Как устроен clipshot (проверено чтением кода)

```rust
Command::new(current_exe).spawn();
std::process::exit(0);
```

- статус только читается (`IOHIDCheckAccess`, `AXIsProcessTrusted`);
  `request_*` — мёртвый код, вызовов нет;
- UI немодальный: баннер, опрос 10 с, `return null` когда всё выдано;
- инструкция: `System Settings → Privacy & Security → … → click + → add Clipshot`.

**Чего копировать нельзя** (`REV_model`): у clipshot строки в Настройках создают
сами рабочие API (`CGEventTapCreate`, `CGEvent.post`) — они прompt'ят. У macVNC
такого пути нет → **«+» несущий**, и путь обязан быть неубиваемым.

## Инварианты

- **I1** один снимок сигналов на рендер;
- **I2** «нужен перезапуск» не показываем как факт — платформа не даёт отличить;
- **I3** системный диалог не поднимаем никогда;
- **I4** сервер работает → панели нет;
- **I5** кнопка всегда активна, тупиков нет;
- **I6** Quit всегда закрывает приложение;
- **I7** перезапуск = `posix_spawn` своего бинарника. Атрибуцию TCC ломает
  **чужой** предок (Terminal), не macVNC. ⚠ измерить, а не постулировать
  (gaps S8): после перезапуска `CGPreflight` из GUI обязан остаться YES.

## Не делаем

- `CGRequestScreenCaptureAccess`, AppleScript-управление Настройками;
- правки TCC.db (SIP не применяет, замеры невалидны);
- перезапуск через `open`/`open -n`;
- авто-перезапуск на произвольное завершение;
- модальные окна на пути прав;
- опрос `CGPreflight` из shell-запуска (всегда NO — атрибуция терминалу).

## Протокол проверки (иначе замеры ложны)

- запуск **только через GUI**: `open /Applications/macVNC.app`;
- сброс адресный: `tccutil reset ScreenCapture net.christianbeier.macVNC`;
- установка `ditto` поверх, никогда `rm -rf`;
- auth только `/tmp/refclient` (vncdotool даёт ложный AUTH_OK);
- бэкап `/Applications/macVNC.app` перед каждой заменой;
- перед каждым замером — убедиться, что запущен **один** экземпляр.

## Известные пробелы, сознательно вне объёма

Отзыв права во время работы, отказ пользователя в системном алерте, запуск как
login item без пользователя у экрана, hot-plug мониторов. Зафиксировано, чтобы
не выдавать за проверенное.
